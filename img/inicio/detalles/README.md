# Fotografías seleccionadas para la sección Detalles

Orden: Materiales, Color y Acabados.

- `materiales.webp` / `materiales-560.webp`
- `color.webp` / `color-560.webp`
- `acabados.webp` / `acabados-560.webp`

Archivos proporcionados por el propietario desde `imagenes web nuevas/2`, copiados sin recodificar.
Principales: 1122 × 1402 px (aproximadamente 4:5). Móviles: 560 × 700 px (4:5).
Se declaran las dimensiones reales, carga diferida, `srcset` de 560w y 1122w y `sizes`
según la cuadrícula existente. Los marcos 4:5 y `object-fit: contain` evitan deformaciones.
Se conserva la animación de descubrimiento y zoom sutil sin filtros ni superposiciones.
Las imágenes son recursos de presentación; no se añaden afirmaciones de clientes o instalaciones.
