# Recursos visuales del proceso

- `preprensa.webp`: recurso de presentación generado, con un diseñador masculino trabajando en su escritorio. No documenta personal ni instalaciones propios.
- Prensa: se conserva `img/optimized/prensa-800.webp`.
- Postprensa: se conserva `img/optimized/postprensa-800.webp`.

Preprensa se convirtió a WebP auténtico, 1280 × 960 px y calidad 92. El archivo recibido tenía extensión `.webp` pero contenía PNG; se conserva sin alterar y existe una copia externa de respaldo.

La sección presenta exclusivamente la imagen activa, las etapas Preprensa / Prensa / Postprensa y los enlaces a Servicios y Productos. No incluye pies descriptivos debajo de las fotografías.
